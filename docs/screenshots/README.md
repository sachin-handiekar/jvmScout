# Screenshots

Drop dashboard screenshots here and the project README will pick them up.

Expected filenames (referenced from the root `README.md`):

| File | What to capture |
|---|---|
| `dashboard.png` | The main dashboard — error timeline, top exception classes, KPIs. |
| `event-detail.png` | A single event: stack trace with per-frame local-variable values. |
| `source-view.png` | The decompiled source view for a stack frame. |
| `alerts.png` | The Alerts screen with one or more rules configured. |

Guidelines:

- Use a wide viewport (≈ 1440px) and the app's dark theme for consistency.
- PNG, trimmed to the app chrome (no OS window borders).
- Keep each image under ~500 KB where possible (optimize with `oxipng`/`pngquant`).
