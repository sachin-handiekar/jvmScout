The problem

Observing a live JVM is supposed to be hard.

Bytecode rewriting agents are heavy. Java profilers add overhead you can't ship to production. jstack is a snapshot, not a story. When something misbehaves in a long-lived service, the only reproducible signal is often a log line that doesn't tell you what you actually needed to know.

The solution

A native agent that speaks JVMTI directly.

jvmScout is a tiny C++ library the JVM loads at startup or via dynamic attach. It hooks the runtime through the standard JVMTI interface — the same one HotSpot's own tools use — so you get method tracing, heap walks, lock monitoring, and class instrumentation with overhead measured in single-digit percent.

✓No bytecode rewriting at build time
✓No Java agent JAR on the classpath
✓Stream events out-of-process
✓Disable hot paths at runtime

How it works

One native library, loaded by the JVM.

The JVM hands the agent a JVMTI environment. The agent registers callbacks. Your data flows out.

Install

Two ways in — pick the one you trust.

A prebuilt binary for getting started, or a source build for production.

↓ Download a release

Prebuilt for Linux, macOS, and Windows.

$ curl -L -o libjvmScout.so \ https://github.com/sachin-handiekar/jvmScout/releases/latest/download/libjvmScout-linux-x86_64.so $ chmod +x libjvmScout.so
libjvmScout.so · Linux libjvmScout.dylib · macOS jvmScout.dll · Windows

⚒ Build from source

Requires a C++17 toolchain, CMake 3.16+, and a JDK.

$ git clone https://github.com/sachin-handiekar/jvmScout.git $ cd jvmScout $ cmake -B build -DCMAKE_BUILD_TYPE=Release $ cmake --build build -j # artifact: build/libjvmScout.so

$ Quick start

$ java -agentpath:/opt/jvmScout/libjvmScout.so -jar yourapp.jar
$ java -agentpath:/opt/jvmScout/libjvmScout.so=trace=com.acme.*,output=/var/log/jvmScout.jsonl,sample_rate=100 \ -jar yourapp.jar
$ jvmScout attach --pid 12345 --options trace=com.acme.checkout.*
event=method_enter thread=http-nio-8080-exec-3 class=com.acme.OrderService method=submit ts=1782059612.041 event=method_exit thread=http-nio-8080-exec-3 class=com.acme.OrderService method=submit dur_us=4821 event=alloc thread=http-nio-8080-exec-3 type=com.acme.Order size=192
